# LLM Application Learning
Remote update practice.
## 学习进度

- **Day 1：Python 基础与 Git 入门** —— 复习常用数据结构、流程控制、函数等 Python 基础，并完成 Git 仓库初始化、提交、推送与 GitHub 基本工作流。
- **Day 2：Python 函数进阶与 JSON** —— 学习默认参数、关键字参数、`*args`、`**kwargs`、`lambda`，并完成 JSON 文件的读取、处理与写入。
- **Day 3：Python 面向对象与工程基础** —— 学习 class、对象、继承、方法重写、异常处理、模块与包，并进一步练习 Git 分支、合并、Revert、Reset、Cherry-pick 等操作。
- **Day 4：Python 进阶与环境管理** —— 学习 Decorator、Generator、CSV、文本处理，并掌握 venv、pip、requirements.txt 等 Python 项目环境管理基础。
- **Day 5：HTTP 与 API 调用** —— 学习 HTTP Request / Response、GET / POST、Headers、JSON Body、状态码和异常处理，使用 `requests` 调用公开 API，并封装基础 `APIClient`。
